# 小兒麻醉
> 衛教單張 · 麻醉部｜編碼 HE-20138
> 對象：家長與照顧者｜閱讀時間約 6 分鐘｜學習評量 5 題
## 前言
當您的小朋友需要在麻醉的狀況下接受外科手術或是檢查，想必會讓您非常憂心，也有很多的疑問。
這裡我們提供簡單的資訊供您參考，也請您詳細地與麻醉醫師討論，以獲得針對孩子狀況更明確的解答。
## 先看重點
- **病史要說清楚**：先天性、遺傳性疾病、用藥史、過敏史與過去麻醉經驗，都是麻醉規劃的重要依據。
- **方式因人而異**：多以全身麻醉進行；幼童可先以肌肉注射或面罩吸入誘導，睡著後再打點滴。
- **家長是安定力量**：恢復室通常會請家長陪伴，減輕孩子焦慮；離院前護理師會說明進食與傷口照護。
## 一、小朋友如何麻醉？
### 1. 術前完整評估
不論您的小朋友需要接受何種治療或是手術，我們都必須詳細地知道小朋友的過去病史，包含**先天性、遺傳性疾病、用藥史、過敏史，甚至是麻醉的經驗**，以提供本次麻醉的參考。
### 2. 選擇合適的麻醉誘導方式
一般小朋友接受麻醉的方式為**全身麻醉**。
- 小小朋友因為無法配合施打點滴，故可以考慮經由**肌肉注射**或是**面罩吸入**麻醉藥劑，待睡著後再施打點滴。
- 大小孩可直接經由點滴加入麻醉藥劑，使其睡著。
### 3. 術中守護與術後恢復
手術／檢查的過程，麻醉醫師會注意小朋友的**生命徵象（呼吸、心跳、血壓、體溫）**，以確保小朋友的安全。
手術或是檢查結束後，會讓小朋友逐漸甦醒，並在恢復室接受後續的照顧。通常會請家長至恢復室陪伴小朋友，以減輕其焦慮。
離開恢復室前，會有護理師向您衛教術後應該注意的照護事項，如**進食時間、傷口照護**等。
## 二、麻醉是否會影響小朋友的生長發育？
儘管近年來一些動物實驗發現，麻醉藥劑似乎會對動物的腦部發育發展造成不等的影響，但是這些動物實驗的結果是否能夠對應到人體上，仍是個很大的未知數。
故在必要的檢查或是手術前，務必和您的小兒科醫師或是執行醫療處置的醫師做充分的溝通，也**不需讓這些證據未明的疑慮延遲必要的治療**。
麻醉醫師一直以來是把**病人安全**視為首要顧念，您可以放心地把小朋友交給專業的麻醉醫師做最妥善的照顧。
## 三、家長安心小提醒
- 主動告知完整病史、先天或遺傳疾病、正在使用的藥物與過敏史。
- 分享孩子過去接受麻醉或手術的經驗，供醫療團隊參考。
- 對麻醉方式或風險有疑問，術前與麻醉醫師充分討論。
- 必要的檢查或手術，不因證據未明的疑慮而延遲。
- 恢復室陪伴孩子，並在離院前確認進食時間與傷口照護方式。
## 四、學習評量（5 題選擇題）
> 請選出最合適的答案，答案與解析附於各題之後。
### 第 1 題
小朋友接受麻醉前，醫療團隊最需要詳細了解下列哪一項資訊？
- A. 小朋友在學校的成績與才藝表現
- B. 先天性與遺傳性疾病、用藥史、過敏史及過去麻醉經驗
- C. 家長的工作地點與上下班時間
- D. 小朋友最喜歡的玩具與卡通角色
**答案：B**
**解析：** 麻醉前必須完整評估過去病史，包含先天性、遺傳性疾病、用藥史、過敏史，甚至是麻醉的經驗，這些都是本次麻醉規劃的重要參考。
### 第 2 題
對於無法配合施打點滴的小小朋友，可以考慮用哪種方式進行麻醉誘導？
- A. 只能等孩子長大後再接受手術
- B. 先由家長抓住孩子強行施打點滴，不使用其他方式
- C. 經由肌肉注射或面罩吸入麻醉藥劑，待睡著後再施打點滴
- D. 讓孩子自行口服安眠藥後走進手術室
**答案：C**
**解析：** 小小朋友因為無法配合施打點滴，可以考慮經由肌肉注射或面罩吸入麻醉藥劑，待睡著後再施打點滴；大小孩則可直接經由點滴加入麻醉藥劑。
### 第 3 題
手術或檢查過程中，麻醉醫師會特別注意小朋友的哪些生命徵象？
- A. 身高、體重、視力、聽力
- B. 血糖、尿酸、膽固醇、三酸甘油脂
- C. 牙齒數目、頭髮長度、指甲顏色
- D. 呼吸、心跳、血壓、體溫
**答案：D**
**解析：** 手術／檢查過程中，麻醉醫師會注意小朋友的生命徵象（呼吸、心跳、血壓、體溫），以確保小朋友的安全。
### 第 4 題
關於「麻醉是否會影響小朋友生長發育」，下列敘述何者正確？
- A. 動物實驗結果已確定同樣會發生在人體，應延遲所有必要手術
- B. 動物實驗結果能否對應到人體仍是未知，不應讓證據未明的疑慮延遲必要治療
- C. 全身麻醉一定會造成腦部永久損傷
- D. 只要接受麻醉，就一定會影響身高發育
**答案：B**
**解析：** 動物實驗結果是否能夠對應到人體仍是很大的未知數。必要檢查或手術前應與醫師充分溝通，但不需讓證據未明的疑慮延遲必要的治療。
### 第 5 題
手術或檢查結束後，關於恢復室的照顧，下列何者正確？
- A. 會讓小朋友逐漸甦醒，通常請家長至恢復室陪伴以減輕焦慮
- B. 小朋友醒來後必須立刻自行走路回家
- C. 恢復室禁止家長陪伴，以免影響護理作業
- D. 離開恢復室前不需要任何術後照護說明
**答案：A**
**解析：** 手術或檢查結束後會讓小朋友逐漸甦醒，並在恢復室接受後續照顧；通常會請家長至恢復室陪伴以減輕焦慮。離開前護理師會衛教進食時間、傷口照護等事項。

function esc(s){
return s.replace(/&/g,'&amp;').replace(/</g,'&lt;').replace(/>/g,'&gt;');
}
function inline(s){
let t = esc(s);
t = t.replace(/`([^`]+)`/g, '<code>$1</code>');
t = t.replace(/\*\*([^*]+)\*\*/g, '<strong>$1</strong>');
t = t.replace(/(^|[^*])\*([^*\n]+)\*/g, '$1<em>$2</em>');

function renderMarkdown(md){
const lines = md.replace(/\r/g, '').split('\n');
let html = '';
let i = 0;
let para = [];
let list = null; // {type:'ul'|'ol'|'tasks', items:[]}
function flushPara(){
if (para.length){
html += '<p>' + inline(para.join('')) + '</p>';
para = [];
}
}
function flushList(){
if (list){
html += '<' + list.type.replace('tasks','ul') + (list.type === 'tasks' ? ' class="tasks"' : '') + '>' + list.items.join('') + '</' + list.type.replace('tasks','ul') + '>';
list = null;
}
}
function flushAll(){ flushPara(); flushList(); }
while (i < lines.length){
const raw = lines[i];
const line = raw.trim();
if (!line){
flushAll();
i++;
continue;
}
// 標題
let m = line.match(/^(#{1,4})\s+(.*)$/);
if (m){
flushAll();
const level = m[1].length;
const tag = level === 1 ? 'h2' : 'h' + Math.min(level, 6);
html += '<' + tag + '>' + inline(m[2]) + '</' + tag + '>';
i++;
continue;
}
// 分隔線
if (/^(-{3,}|\*{3,})$/.test(line)){
flushAll();
html += '<hr>';
i++;
continue;
}
// 引用
if (/^>\s?/.test(line)){
flushAll();
const buf = [];
while (i < lines.length && /^>\s?/.test(lines[i].trim())){
buf.push(lines[i].trim().replace(/^>\s?/, ''));
i++;
}
html += '<blockquote><p>' + buf.map(inline).join('<br>') + '</p></blockquote>';
continue;
}
// 任務清單
m = line.match(/^-\s+\[([ xX])\]\s+(.*)$/);
if (m){
flushPara();
if (!list || list.type !== 'tasks'){ flushList(); list = { type:'tasks', items:[] }; }
const key = 't' + (taskSeq++);
const checked = m[1].toLowerCase() === 'x' ? ' checked' : '';
list.items.push('<li><label class="task"><input type="checkbox" data-task="' + key + '"' + checked + '><span class="box"></span><span class="txt">' + inline(m[2]) + '</span></label></li>');
i++;
continue;
}
// 無序清單
if (/^[-*]\s+/.test(line)){
flushPara();
if (!list || list.type !== 'ul'){ flushList(); list = { type:'ul', items:[] }; }
list.items.push('<li>' + inline(line.replace(/^[-*]\s+/, '')) + '</li>');
i++;
continue;
}
// 有序清單
m = line.match(/^\d+\.\s+(.*)$/);
if (m){
flushPara();
if (!list || list.type !== 'ol'){ flushList(); list = { type:'ol', items:[] }; }
list.items.push('<li>' + inline(m[1]) + '</li>');
i++;
continue;
}
// 一般段落
flushList();
para.push(line);
i++;
}
flushAll();
return html;
}

function splitDoc(md){
const lines = md.replace(/\r/g, '').split('\n');
const h1 = lines.findIndex(function(l){ return /^#\s+/.test(l.trim()); });
let title = '小兒麻醉';
const meta = [];
let bodyStart = 0;
if (h1 >= 0){
title = lines[h1].trim().replace(/^#\s+/, '');
let j = h1 + 1;
while (j < lines.length && !/^##\s+/.test(lines[j].trim())){
const l = lines[j].trim();
if (/^>\s?/.test(l)) meta.push(l.replace(/^>\s?/, ''));
j++;
}
bodyStart = j;
}
let body = lines.slice(bodyStart).join('\n');
// App 內以互動測驗呈現靜態測驗段；學習回饋獨立放到測驗之後。
// 參考資料與聯絡資訊屬於衛教內容，保留在教材最後（測驗解鎖前）。
const qs = body.indexOf('## 四、學習評量');

let refsAt = body.indexOf('## 參考資料');
if (refsAt < 0) refsAt = body.indexOf('## 製作單位與聯絡資訊');
if (refsAt < 0) refsAt = body.length;
let reflect = '';
if (rs >= 0) reflect = body.slice(rs, refsAt);

body = body.slice(0, contentEnd) + (refsAt < body.length ? body.slice(refsAt) : '');
return { title: title, meta: meta, body: body, reflect: reflect };
}
